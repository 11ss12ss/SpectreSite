Privacy

Last updated November 21, 2026

Spectre keeps what it needs to moderate your server and nothing more. Here's exactly what that is.

What it stores

  • Server settings you choose with commands or the dashboard.
  • Moderation cases (warns, mutes, kicks, bans, notes): user ID, moderator ID, reason, time, and any appeal text.
  • Ticket status, and verification join time while someone is unverified.
  • Temp-ban timers.
  • Daily totals per server of joins, leaves and messages for the dashboard's analytics. These are counts only, never the messages.

What it doesn't store

Message content, files, voice, and direct messages. Edit and delete logs are posted to a log channel in your own server, not kept by Spectre.

The dashboard and signing in

Signing in uses Discord's login with the identify scope only. That gives Spectre your Discord user ID, name and avatar, and a list of servers you're in, so it can show the ones you manage. The access token is used once and then revoked. You stay signed in with a session that lives on Spectre's server and expires, and signing out ends it. The dashboard's traffic passes through Cloudflare, which handles the connection to protect it from abuse.

The site itself has no analytics or ad trackers. Its fonts load from Google Fonts.

Staff actions

When Spectre's owners remove the bot from a server for breaking the Terms, we record the server, the rule, who did it and when. This is kept so we can handle appeals.

Your control

  • /data info shows what's kept for your server.
  • /data delete_user erases one person's records.
  • /data delete_server erases everything for your server.
  • If Spectre leaves a server, its data is erased after 30 days.

Sharing

We don't sell data or share it with advertisers. Spectre runs on a hosting provider and uses Google's Firestore database to store the data above. We may disclose data if the law requires it.

Contact and changes

Questions or deletion help: the support server. If we change this page, the date above changes with it.
